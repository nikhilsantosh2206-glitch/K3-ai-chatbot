# K3 AI Chat

## 🤖 Overview
K3 AI Chat is an intelligent assistant built with **Flask** and powered by **OpenRouter API**.  
It provides a simple yet powerful interface for AI conversations, smart responses, and chat history management.

---

## 🚀 Features
- Flask‑based backend for smooth API integration  
- Responsive UI for AI chat interactions  
- OpenRouter API for real‑time intelligent responses  
- Chat history management and smart response options
